# HBTC-Copy 自动挖矿 DApp PRD
版本 0.1 · 2026-09-10 · 产品基线草案
负责人：用户负责业务决策；本任务负责产品拆解、实现协调和测试验收。
关联：[研究](00-research.md)、[状态与数据](02-models.md)、[验收及迭代](03-delivery.md)。

## 目标与范围
面向已持有目标链资产、希望按预算重复参与 PoSwap 的用户，提供无需导入私钥的策略执行、透明收费、奖励与支出对账以及随时退出能力。商业价值是执行服务与可核验数据，不是许诺挖矿回报。

MVP：单链、单一已核验矿池、一个账户仅一条活动策略、按矿块定额买入、手动领取、点数计费、历史导出、暂停/链上撤销。只读浏览免费。
后续：自动领取、更多策略、多个矿池。自动卖出/复投、代币发行、跨链桥、跟单、收益分成、推荐返佣均不在 MVP。HBTC-Copy 暂指新项目，不意味着本轮获准开发或部署其底层发行协议。

成功指标：重复执行/错误扣费为 0；授权越界测试全部拒绝；每项资产/费用可追溯；有效执行机会的完成率（剔除用户预算/额度不足等明确跳过）；收费后留存和退款率。无数据前不设虚构收益目标。

## 用户故事
- US01：不连接钱包就能理解机制、查看数据新鲜度与费用规则。
- US02：连接自己的钱包，确认策略会花多少、执行哪些操作、奖励到哪里。
- US03：购买执行次数，查看每次扣费依据及失败是否收费。
- US04：关闭页面后仍按已批准规则执行，并能重新连接查看。
- US05：暂停策略、撤销权限、领取奖励和取回未花预算，不依赖平台客服。
- US06：对比已支付成本、买到资产、挖矿奖励与可实现价值，不把预计值误当盈利。

## 授权与技术路线决策
连接钱包只建立账户会话；登录签名不等于交易许可。ERC-20 approve 只涉及 Token 额度，不能直接授权后台花费 EOA 的原生 ETH。相关标准见研究 E08/E09。

首选候选：用户控制的智能账户 + 链上受限执行策略 + 后台 keeper。用户通过钱包创建/批准规则；用户私钥始终在钱包内。keeper 使用平台自己的运行凭据付 Gas/提交调用，但链上规则限制其动作，不能更换资产接收者或任意转账。默认不在 DApp 生成或保存用户会话私钥。4337 是可选执行传输方式，不是自动安全保证，也不能假定目标链已有可用 Bundler。

备选：用户批准、有限预算的策略合约，资金进入可由用户独立撤回的隔离余额；平台不能自由提取本金。需新增合约并审计，不能宣传为资金完全留在原 EOA。
降级：若目标只能由 EOA 自己调用且不支持安全委托，提供每次钱包确认的半自动模式，清楚标注需在线。不得将其验收为“关闭页面仍自动”。

进入真实自动开发之前必须用目标合约证明：支持合约账户调用；可以可靠指定矿工；买入资产/奖励归属正确；可限制 Router 内所有子命令；可撤销；费用可限额；失败不会部分挪走资金。

## 业务规则
| ID | 规则 |
|---|---|
| BR01 | 页面、API、存储、日志均不提供导入、采集、保存用户私钥/助记词能力，包括“加密保存”入口。钱包拥有者签名由钱包完成。 |
| BR02 | HBTC-Copy 部署资料未核验或链不匹配，真实购买/授权/挖矿不可用；演示数据全局标明模拟。 |
| BR03 | 支出账户、矿工归属、代币接收者、奖励接收者在策略确认页展示并绑定；平台不能更换。 |
| BR04 | 策略包含每次最大输入、总本金预算、累计 Gas/平台费用上限、最大成功次数、有效期、最小间隔与执行窗口。实际总支出不得超过分别批准的上限。 |
| BR05 | 授权约束 chainId、具体合约/池、完整允许动作、接收者、Token、最大额度、策略版本、nonce、到期时间。禁止任意 calldata、delegatecall、任意 multicall；必须验证 Router 内嵌命令。 |
| BR06 | 增加预算/范围、延长有效期、改变接收者必须重新签名。签名绑定域、链、验证合约及 nonce，跨链/跨策略不可重放。 |
| BR07 | MVP 每账户每矿块最多一次成功买入；单账户仅一条活动策略。以链上协议矿块确定归属；跨边界执行应拒绝或重新报价，不把交易误计入旧矿块。 |
| BR08 | offset 位于 [0, 矿块长度)，截止窗口不越矿块；已错过窗口跳过，不补单、不累计补跑。有效机会不等于保证上链。 |
| BR09 | 过期报价、数据过旧、Gas 超限、价格冲击/滑点超限、RPC 分歧、余额/点数不足均不广播，明确跳过或暂停原因。重试遵循 BR07。 |
| BR10 | 发送结果未知时保留预算和点数预留，先查原交易/nonce；不得认为失败而新 nonce 重发。重组先回滚派生状态再对账。 |
| BR11 | 页面“暂停”停止平台新增调度；“撤销授权”是链上交易，确认后权限失效。断开钱包连接不等于撤销。已广播交易可能仍完成；页面提示在途风险。 |
| BR12 | 用户可绕过平台直接链上撤销/取回未花预算。平台故障、停服、点数耗尽不得阻挡领取、撤销和退出。 |
| BR13 | 点数仅为服务次数，不是 HBTC work、不兑换代币、不代表投资收益。每次成功且完成确认的买入扣 1 点；失败/拒签/跳过/重放不扣服务点数；失败 Gas 单列。 |
| BR14 | 点数购买按已签署订单版本结算，需链、Token、收款、金额、订单号匹配；确认后入账，事件幂等。MVP 点数绑定付费钱包+链，不转让、不自动过期。 |
| BR15 | 点数预留→结算/释放；先预留才调度。重组冲正，禁止删除原账。免费手动领取/退出指不扣平台点数，用户仍可能付 Gas。 |
| BR16 | 默认固定套餐计费，售价/币种待定；参考网站价格只用于研究。MVP 不另抽收益分成、不自动续费。平台不得静默改变已购权益。 |
| BR17 | 退款只对未使用且未预留的已购次数，按订单成交金额×退款次数/原套餐次数向下取最小单位；最后全额退剩余时处理舍入残差。原链原币原付费地址退回；先锁定额度再退款，重试不重复退款。实际商业启用前确认期限与结算方案。 |
| BR18 | 买入本金、协议 toll、池费、Gas、平台费逐项展示；已包含在输入中的费用不得再从总支出重复扣除。预计回购金额不等于个人收益。 |
| BR19 | 当前矿块预计奖励、封闭矿块可领、已领取、买入获得资产分开展示；领取只改变位置，不重复记奖励收入。卖出不计 work（目标核验通过后启用该规则）。 |
| BR20 | 所有金额使用整数最小单位；币种、decimals、时间戳、数据区块和确认级别必须随值保留。未知是空值，不是零。 |
| BR21 | 管理后台只能停新任务、调整新套餐、查看服务健康和按凭证处理退款；不能提取用户本金、替用户签扩大权限或修改已结算账本。 |
| BR22 | 默认禁用主网广播和收费；目标配置核验、测试网/fork 验收、安全检查通过后才允许启用。 |

## 仪表盘与收益口径
主卡：运行状态、下一执行机会、剩余本金预算/费用预算、剩余次数、已确认 work、预计/可领/已领奖励。次卡：累计买入支出、买到的 Token、协议费、Gas、已消费服务费、授权到期、链上撤销入口。

按策略独立核算，外部转入转出必须标记。资产口径：
策略盈亏估算 = 当前策略归属资产价值 + 已转出/已卖出所得 − 累计外部投入。
该资产集合包含仍持有的买入代币、已领但未转出的奖励、可领的已封闭奖励、剩余执行现金；未封闭预计奖励单列且不进入确定收益。已从资产流出体现的费用不再重复扣除；未包含的平台费用按归属分摊一次。

同时展示原币数量，美元价值附价格时间/来源；没有可靠报价时不显示美元净收益。市价估值与按可成交报价扣滑点/费用后的退出估值区分。不可把“奖励数增加”写成盈利。年化收益在 MVP 不展示。

## 主要页面与交互
1. 首页：项目身份与链、机制摘要、数据更新时间、免费只读入口、连接钱包。没有数据时显示加载/不可用原因，不能用 0 充当真实读数。
2. 控制台：运行卡始终首屏；矿块倒计时注明协议窗口；资产、费用、奖励分组；每张卡可展开数据来源与交易明细。
3. 创建策略：选择已核验池→填写每次金额/次数/预算/offset/截止窗口/滑点/Gas 上限/有效期→预检→展示完整权限与最大损失预算→钱包签名→等待链上生效→“启动”。签名取消保留草稿，不扣点。
4. 购买：套餐次数、币种、总价、单价、有效期/退款规则；不足额度时明确分成授权和支付两步；支付未知时显示查询中，不能诱导再买一次。
5. 授权中心：钱包连接、Token allowance、策略授权分开列出；权限范围、剩余额度、到期和独立链上撤销入口。暂停与撤销按钮文案不同。
6. 历史：按策略/时间/状态筛选，展示跳过原因、费用、矿块、交易哈希、确认状态、点数流水；支持 CSV，数值保留原始精度。跨设备以服务账本+链上记录恢复，不能只取本地缓存。
7. 奖励：预计/可领/已领分区；“领取”附 Gas 估计；不要求购买点数。若目标需分批，显示每批进度及剩余范围。
8. 退出：先暂停→查看在途任务→撤销→链上确认→用户取回余额；不自动卖出用户资产。

异常文案示例：“交易已提交，正在核实结果；本次预算已预留。”“平台已暂停新任务；1 笔已广播交易可能继续确认。”“授权已到期，需要重新批准后才能执行。”
移动端适配 360px；表格卡片化；键盘可操作、焦点可见、错误与颜色同时用文字表达。签名摘要不在钱包外伪造成功状态。

## 默认服务指标（产品目标，非已测成绩）
读取每 15 秒刷新；连续 30 秒无可信区块更新显示陈旧并停止新执行（阈值在目标链测试后版本化）。前端已接收状态 5 秒内更新；API 常规读请求 p95 < 1 秒，以 100 并发会话基线压测。后端自动化需跨浏览器关闭持续运行；RPC 失败指数退避，上限 30 秒；单个机会最多 3 次预广播重试，越窗口跳过。广播未知不适用重发重试。
公开状态页/日志不含签名、凭据、完整请求敏感体。私有策略 API 用钱包所有权挑战登录：单次 nonce、域、链、到期、服务端校验；智能钱包支持相应签名验证。任何地址查询公共链上数据与访问私有策略需区分权限。
