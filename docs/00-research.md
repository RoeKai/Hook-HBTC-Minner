## 结论与证据边界
HBTC-Copy 是用户给出的新项目名称。新项目官网、链、合约、ABI、源码、部署状态均未提供；“同模式”不能作为字节码等同或参数一致的证明。本文所有 HBTC 参数仅用于参考，不得成为 HBTC-Copy 的生产默认值。

本轮读取了官方文档、第三方工具的真实浏览器页面和 GitHub 初始化状态。未输入私钥、连接钱包、签名、充值或发送交易。官方交互页的网页读取结果显示 RPC unreachable；第三方页面稍后显示了动态数据，但其数据尚未通过独立 RPC 对账。合约浏览器未返回可读源码，公开合约 API 读取失败；本地网络解析失败，网络扩展请求中止。因此以下“官方说明”与“页面观察”均不能升级为“源码/链上验证”。

## HBTC 产品与经济机制（依据 E02–E05）
用户买入经过指定池与 Hook，买入费用形成当前矿块的 work。买到的代币与额外挖矿奖励是两项资产，不能把两者合并称为“挖矿收入”。卖出仍付费但不增加 work；自动买卖循环不能宣传为无风险收益。

白皮书公式：R_i = S_b × w_i / max(W_b, T_b)。S_b 是该矿块计划奖励，w_i 为用户工作量，W_b 为全矿块工作量，T_b 为目标工作量。矿块未结束时 W_b 仍会变，估算不是已得奖励；低于目标时少发部分不补发。空矿块无工作量时不发奖励。

官方描述每 600 秒一个矿块、每 4,320 矿块减半；前 144 矿块用于创世流动性。此处矿块是协议时间窗口，并非底层链的区块。交易开放还涉及 settleGenesis 与 flushPol，不能只看倒计时。费用据官方说明有 1%–10% 边界。回购网存在 keeper 激励，回购维护与用户买入挖矿、奖励领取是不同操作。本文不将“无管理员、不可升级、流动性不可取出”判为已审计事实。

## HBTC 链上交互地图（待源码复核）
1. 读取网络、池和 Hook 状态 → 报价/模拟 → 钱包签名买入 → Router → PoolManager → Hook 记录 work。
2. 买入代币接收者、work 归属地址、奖励领取地址必须逐项验证。官方文档称默认归属 tx.origin，hookData 可指定矿工。使用执行器/智能账户时尤其不能省略归属验证。
3. 矿块封闭后查询 pendingRewards(address)，构造实际 ABI 支持的领取调用。领取函数签名、分页/批量上限、奖励接收者约束尚未获取，不猜测。
4. 卖出据 FAQ 使用 Permit2；代币额度授权、Permit2 签名授权和挖矿策略授权不是同一权限。
5. 维护回购网可能涉及 poke/harvest，暂不纳入新产品付费挖矿次数。
